<h1 align="center">R³Coach</h1>

<h3 align="center">Reconstruction, Recommendation, and Responsive Guidance for In-situ XR Fitness Training</h3>

**R³Coach is a multi-agent in-situ XR training system that supports personalized training tailored to users’ needs.** It integrates Reconstruction for in-situ self-observation, Recommendation for intent-driven movement selection, and Responsive Guidance for actionable corrective guidance. By combining multimodal retrieval with 3D motion generation, R³Coach helps learners find movements suited to their individual needs and follow personalized guidance to improve their execution.
